# 🥗 FreshGuard AI

**FreshGuard AI** is a smart grocery and food expiry management application designed to reduce food waste by tracking expiry dates, providing timely reminders, and offering insights through analytics.  
Built with modern web technologies and designed for future AI-powered intelligence.

---

## 🚀 Features

- 📦 **Inventory Management**
  - Add food and grocery items with expiry dates
  - Automatic status detection: *Fresh, Expiring Soon, Expired*

- ⏰ **Expiry Awareness**
  - Highlights items nearing expiry
  - Reduces food waste through early alerts

- 📊 **Analytics Dashboard**
  - Visual insights on consumed vs wasted items
  - Helps improve consumption habits

- 🛒 **Smart Grocery List**
  - Maintain a separate grocery checklist
  - Designed for daily household use

- 🤖 **AI-Ready Architecture**
  - Integrated Gemini AI SDK (future-ready)
  - Designed for recipe suggestions and smart predictions

- 💾 **Local Persistence**
  - Uses browser `localStorage`
  - No data loss on refresh

---

## 🛠️ Tech Stack

- **Frontend:** React 19 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **AI SDK:** Google Gemini (placeholder)
- **State Storage:** LocalStorage
